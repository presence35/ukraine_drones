# Changelog

## [Unreleased]

- Fix: tapping the "N threats resolved" tally notification no longer silently drops the replay — the show now waits out transient states (cold start, Settings open, shelter overlay) and plays the moment the map is actually visible; with the Shoot-down animation toggle off it explains itself via a toast, and a live alert in your zone still cancels it (safety first, now audited). The Debug log gains a "Shoot-down show" entry recording each tap's outcome. / Виправлення: натискання сповіщення «N загроз знешкоджено» більше не мовчки втрачає повтор — шоу чекає на перехідні стани (холодний старт, відкриті налаштування, укриття) і грає щойно мапа справді видима; якщо вимкнено «Анімацію знешкодження», застосунок пояснює це тостом, а активна тривога у вашій зоні досі скасовує показ (безпека понад усе, тепер із записом у журналі). Журнал налагодження отримує запис «Шоу знешкодження» із результатом кожного натискання.

- Settings: "Haptic feedback" moved from Just Fun to System & Display, and press ticks now actually vibrate — they fire through the same always-on vibrator channel as the shoot-down flourish instead of the system touch-feedback API that most devices ignore or mute. / Налаштування: «Тактильний відгук» переїхав із «Просто розваги» до «Системи та інтерфейсу», і натискання тепер справді вібрують — через той самий завжди-активний віброканал, що й анімація збиття, замість системного API тактильного відгуку, який більшість пристроїв ігнорує або глушить.

- Settings: the "City level" alert-scope toggle (and the other nested rows under icon'd toggles) is now properly indented under its parent, so it reads as a subset of "Official alerts". The small threat card hugs its content when GPS is off (no more full-width border stretch). The footer now shows the calm message / "No relevant threats" after a long-press shoot-down instead of repeating the popup's "Wishful thinking…". / Налаштування: перемикач «Міський рівень» (та інші вкладені рядки під перемикачами з іконками) тепер правильно відступає під батьківським рядком і виглядає підмножиною «Офіційних тривог». Маленька картка загрози обіймає свій вміст, коли GPS вимкнено (більше не розтягується на всю ширину рамкою). Нижня панель після збиття довгим натисканням тепер показує заспокійливе повідомлення / «Немає актуальних загроз» замість повтору «Тільки бажання…» з картки.
