# Changelog

## [Unreleased]

- Fix: an official oblast alert now rings exactly once per alert episode — no repeats. All three re-ring paths are closed: (1) Android killing and restarting the alert service mid-alert no longer re-rings it (the announced episode survives restarts in prefs, loaded race-free before the first tick); (2) toggling official alerts off/on no longer re-announces an alert that already rang — an alert that starts while muted still announces on re-enable; (3) a new drone in the oblast no longer re-posts the alert if you tapped or swiped it away — the reason-text refresh stays silent or is skipped, never a brand-new siren. / Виправлено: офіційна тривога області тепер звучить рівно один раз за епізод — без повторів. Закрито всі три шляхи повтору: (1) вбивство та перезапуск сервісу сповіщень Android під час тривоги більше не озвучує її повторно (оголошений епізод зберігається в налаштуваннях і завантажується без гонки до першого такту); (2) вимкнення та повторне ввімкнення офіційних тривог більше не озвучує тривогу, що вже лунала — тривога, що почалась під час вимкнення, усе ще озвучується при ввімкненні; (3) новий дрон в області більше не відновлює сповіщення, якщо ви вже натиснули або прибрали його — оновлення тексту причини лишається тихим або пропускається, але ніколи не стає новою сиреною.

- Fix: the shoot-down replay now plays even while an official alert is live in your area — it's an explicit tap, so it no longer drops silently with a confusing "another alert posted first" log line. A brand-new alert onset mid-show still clears it so the alarm owns the screen. / Виправлення: повтор шоу знешкодження тепер грає навіть під час офіційної тривоги у вашій зоні — це свідомий дотик користувача, тож більше не зникає мовчки з незрозумілим записом «інша тривога вийшла першою» в журналі. Якщо нова тривога починається посеред шоу, воно досі зникає, щоб тривога володіла екраном.

- Popup card: the course line is hidden when it only repeats the type and location already shown under the title (e.g. "UAV - Kobleve, Mykolaiv oblast" over a "Kobleve · Mykolaiv oblast" header); real sentences like "patrolling over the sea" still show. Small card: title now aligns with the big card's title, the reliability letter is larger and the skull smaller. / Картка загрози: рядок курсу ховається, якщо він лише повторює тип і локацію з-під заголовка (напр. «БпЛА - Коблеве, Миколаївська область» над шапкою «Коблеве · Миколаївська область»); справжні речення на кшталт «патрулює над морем» лишаються. Мала картка: заголовок вирівняно як на великій картці, літера надійності більша, череп менший.

- Fix: tapping the "N threats resolved" tally notification no longer silently drops the replay — the show now waits out transient states (cold start, Settings open, shelter overlay) and plays the moment the map is actually visible; with the Shoot-down animation toggle off it explains itself via a toast, and a live alert in your zone still cancels it (safety first, now audited). The Debug log gains a "Shoot-down show" entry recording each tap's outcome. / Виправлення: натискання сповіщення «N загроз знешкоджено» більше не мовчки втрачає повтор — шоу чекає на перехідні стани (холодний старт, відкриті налаштування, укриття) і грає щойно мапа справді видима; якщо вимкнено «Анімацію знешкодження», застосунок пояснює це тостом, а активна тривога у вашій зоні досі скасовує показ (безпека понад усе, тепер із записом у журналі). Журнал налагодження отримує запис «Шоу знешкодження» із результатом кожного натискання.

- Settings: "Haptic feedback" moved from Just Fun to System & Display, and press ticks now actually vibrate — they fire through the same always-on vibrator channel as the shoot-down flourish instead of the system touch-feedback API that most devices ignore or mute. / Налаштування: «Тактильний відгук» переїхав із «Просто розваги» до «Системи та інтерфейсу», і натискання тепер справді вібрують — через той самий завжди-активний віброканал, що й анімація збиття, замість системного API тактильного відгуку, який більшість пристроїв ігнорує або глушить.

- Settings: the "City level" alert-scope toggle (and the other nested rows under icon'd toggles) is now properly indented under its parent, so it reads as a subset of "Official alerts". The small threat card hugs its content when GPS is off (no more full-width border stretch). The footer now shows the calm message / "No relevant threats" after a long-press shoot-down instead of repeating the popup's "Wishful thinking…". / Налаштування: перемикач «Міський рівень» (та інші вкладені рядки під перемикачами з іконками) тепер правильно відступає під батьківським рядком і виглядає підмножиною «Офіційних тривог». Маленька картка загрози обіймає свій вміст, коли GPS вимкнено (більше не розтягується на всю ширину рамкою). Нижня панель після збиття довгим натисканням тепер показує заспокійливе повідомлення / «Немає актуальних загроз» замість повтору «Тільки бажання…» з картки.
